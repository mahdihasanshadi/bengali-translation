# Meaning traps: words that change sense, idioms, and stock phrases

English UI copy is full of short words with many senses. Translation goes wrong
when the dictionary's first sense is used instead of the sense on this screen.
Always decide the sense from context (key name, element type, neighbouring
strings) before choosing a Bengali word.

## 3. Negative and error vocabulary

English error words are harsher or more legalistic when translated literally.

| English | Use | Avoid, and why |
|---|---|---|
| Invalid | সঠিক নয় / ভুল | অবৈধ (means "illegal") |
| Illegal character | এই অক্ষরটি ব্যবহার করা যাবে না | বেআইনি অক্ষর |
| Failed | হয়নি / ব্যর্থ হয়েছে | "ফেল" |
| Fatal error | গুরুতর সমস্যা | মারাত্মক / প্রাণঘাতী ত্রুটি |
| Denied / Forbidden | অনুমতি নেই | নিষিদ্ধ, প্রত্যাখ্যাত |
| Expired | মেয়াদ শেষ হয়েছে | মৃত |
| Terminate | বন্ধ করুন / শেষ করুন | হত্যা, খতম |
| Wrong password | পাসওয়ার্ডটি ভুল | খারাপ পাসওয়ার্ড |
| Bad request | অনুরোধটি সঠিক নয় | খারাপ অনুরোধ |
| Oops! | দুঃখিত! | উফ!, ওহো! |
| You must… | …করতে হবে | আপনাকে অবশ্যই… (heavy; use sparingly) |

A good Bengali error message says what happened and what to do, politely:
"কোনো সমস্যা হয়েছে। কিছুক্ষণ পর আবার চেষ্টা করুন।"

## 5. Marketing language

Headlines and taglines are rewritten (transcreated), keeping the promise and
the energy rather than the words. Bengali marketing copy is concrete and warm;
stacked English adjectives sound empty when carried over.

| English | Weak literal | Better |
|---|---|---|
| Seamless experience | বিরামহীন অভিজ্ঞতা | ঝামেলাহীন অভিজ্ঞতা |
| Powerful tools | শক্তিশালী সরঞ্জাম | কাজের সব টুল / দারুণ সব টুল |
| Unlock your potential | আপনার সম্ভাবনা আনলক করুন | নিজের সেরাটা বের করে আনুন |
| Boost your sales | আপনার বিক্রয় বুস্ট করুন | বিক্রি বাড়ান |
| Take your business to the next level | আপনার ব্যবসাকে পরবর্তী স্তরে নিন | ব্যবসাকে নিয়ে যান আরও এগিয়ে |
| Trusted by 10,000+ customers | ১০,০০০+ গ্রাহকদের দ্বারা বিশ্বস্ত | ১০,০০০-এর বেশি গ্রাহকের আস্থা |
| Get started for free | বিনামূল্যে শুরু করা পান | ফ্রিতে শুরু করুন |
| Built for teams | দলের জন্য নির্মিত | টিমের জন্য তৈরি |
| Limited time offer | সীমিত সময় প্রস্তাব | সীমিত সময়ের অফার |
| Best seller | সেরা বিক্রেতা | সবচেয়ে বেশি বিক্রীত / বেস্ট সেলার |
| Solutions | সমাধানসমূহ | সমাধান / সেবা |
| World-class | বিশ্ব-শ্রেণি | বিশ্বমানের |
| Cutting-edge | কাটিং-এজ | অত্যাধুনিক |
| Hassle-free | ঝামেলা-মুক্ত | ঝামেলাহীন / ঝামেলা ছাড়াই |

Taglines and slogans should be flagged for the client's sign-off; offer one or
two alternatives when the line is central to the brand.

## 7. Fragments and concatenation

Sites sometimes build sentences from pieces ("You have " + n + " new " +
"messages"). English word order will not survive in Bengali, where the verb
comes last and suffixes attach to nouns.

- If you can edit the code, merge the pieces into one string with placeholders,
  then translate the whole sentence.
- If you cannot, translate each piece so that it reads acceptably in the fixed
  order, prefer a label-style rewrite ("নতুন মেসেজ: {n}"), and report the string
  as a known limitation.
- Never translate a fragment such as "of", "by", "in" or "and" in isolation
  without finding the sentence it belongs to. "Page 2 of 10" is
  "পৃষ্ঠা ২ / ১০" or "১০টির মধ্যে ২ নম্বর পৃষ্ঠা", not "পৃষ্ঠা ২ এর ১০".
